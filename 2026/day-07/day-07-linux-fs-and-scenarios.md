# Part 2: Scenario-Based Practice

## Scenario 2: High CPU Usage

### Situation

The server becomes slow and applications start lagging.

---

## Step 1: Check Live CPU Usage

### Command

```bash id="9fkmfc"
top
```

### Why

Displays live CPU and memory usage of running processes.

---

## Step 2: Interactive Process Monitoring

### Command

```bash id="6qh3f2"
htop
```

### Why

Provides a cleaner and more interactive process monitoring interface.

---

## Step 3: Find Top CPU Consuming Processes

### Command

```bash id="hxxepq"
ps aux --sort=-%cpu | head -10
```

### Why

Lists processes sorted by highest CPU usage.

---

## Step 4: Stop Problematic Process

### Command

```bash id="zj9gq6"
kill -9 <PID>
```

### Why

Stops a process that is consuming excessive CPU resources.

---

# Key Learning

* Linux filesystem hierarchy helps locate configs, logs, binaries, and user files quickly.
* `/etc` is important for configurations.
* `/var/log` is important for troubleshooting logs.
* CPU troubleshooting requires monitoring, identifying, and investigating processes step by step.
