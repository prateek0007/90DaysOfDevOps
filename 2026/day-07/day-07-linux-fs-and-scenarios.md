Scenario 2: High CPU Usage
Step 1

Command:

top

Why:
Displays live CPU and memory usage.

Step 2

Command:

htop

Why:
Provides an interactive process monitoring interface.

Step 3

Command:

ps aux --sort=-%cpu | head -10

Why:
Lists top CPU-consuming processes.

Step 4

Command:

kill -9 <PID>

Why:
Stops a problematic process if necessary.
